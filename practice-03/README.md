## Организация кода

task-service.js — реализует функции из ПР2: поиск задачи, переключение статуса, удаление и расчёт сводки; DOM не используется.

task-selectors.js — содержит getVisibleTasks, которая возвращает задачи, соответствующие фильтру all/pending/completed, при этом исходный массив остаётся неизменным.

task-view.js — отвечает за построение карточек (createTaskElement), отображение списка, сводки и заглушки при пустом списке; любой текст вставляется через textContent.

main.js — управляет состоянием и подписывается на события.

Полный перечень задач сохраняется в currentTasks, текущий фильтр — в currentFilter. Видимый набор задач формируется отдельно внутри renderApp. Для обработки кликов по списку и фильтрам применяется делегирование: по одному слушателю на ul#task-list и на #task-filters, а нужная кнопка находится через closest. Сводка рассчитывается в renderSummary с помощью getTaskStats(currentTasks) на основе всего массива задач.

## Отладка и клавиатура
Точка останова: handleTaskListClick, строка чтения const rawId = card.dataset.taskId;.

Значения при клике по span.action-label карточки id = 4:

| Выражение | Значение |
|---|---|
| event.target | span.action-label |
| event.currentTarget | ul#task-list |
| card.dataset.taskId |	"4" (string) |
| Number(card.dataset.taskId) | 4 (number) |
| button.dataset.action	| "toggle" |
| findTaskById(currentTasks, 4) |	{ id: 4, title: "Подготовить модель задач", completed: false, priority: "high" } |
| setTaskCompleted(currentTasks, 4, true) |	{ ok: true, tasks }, задача id = 4 → completed: true |
| currentTasks после |	новый массив, demoTasks не изменён |
Клавиатура. Tab доводит фокус до кнопок toggle/delete и кнопок фильтра. Enter и Space на кнопке действия срабатывают так же, как клик. После toggle фокус остаётся на той же кнопке (карточка перерисована, restoreTaskFocus возвращает фокус). После delete кнопки больше нет — фокус переходит на активный фильтр.
